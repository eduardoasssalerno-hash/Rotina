# 3S Rotina

App pessoal da Ione para rotina, estudos, treino e dinheiro: tarefas, semana e mês, projetos como planetas, modo foco, calistenia e gastos.

- Código: React + Vite, app instalável (PWA).
- Banco e login: Supabase (projeto `rotina`, região São Paulo).
- Publicação: Cloudflare Workers, ligado a este repositório.
